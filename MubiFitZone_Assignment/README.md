# Mubi Fit Zone — HTML & CSS Website Assignment

A fresh, responsive 12-page fitness website built with **HTML5 and CSS3 only**. It is a new assignment project, separate from any previous WordPress/XAMPP website.

## Pages
1. `index.html` — Home
2. `about.html` — About
3. `programs.html` — Programs
4. `strength.html` — Strength Training
5. `cardio.html` — Cardio
6. `yoga.html` — Yoga & Mobility
7. `trainers.html` — Trainers
8. `pricing.html` — Membership
9. `schedule.html` — Class Schedule
10. `nutrition.html` — Nutrition
11. `gallery.html` — Gallery
12. `contact.html` — Contact

## Run locally
Open `index.html` in a browser. Images and Google Fonts load online, so an internet connection is needed for those assets.

## Publish on GitHub Pages (free)
1. Create a **public** repository on GitHub, e.g. `mubi-fit-zone`.
2. Upload all files in this folder (HTML pages, `style.css`, and `README.md`) to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish, then copy the live URL shown in Settings → Pages.
6. Submit both the repository URL and live URL to your instructor.
